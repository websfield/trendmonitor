## CODEX SAYS (outside voice, verbatim)

> - **[P1] Workspace deletion hides its recovery controls.** [workspace-scope.ts:38] creates a replacement workspace once the original is tombstoned. Account Settings then cannot find the original pending deletion. Cancelling through the underlying API restores a second membership, causing subsequent workspace resolution to refuse access.
> - **[P1] Generation settlement can deadlock with Stripe webhooks.** [generate.ts:1609] acquires the money lock before membership locks; [webhooks.ts:1017] takes them in reverse order. Concurrent execution can abort settlement after vendor spend and clear the generated candidate.
> - **[P1] Failed payments reopen expired grace periods.** [webhooks.ts:2271] assigns a fresh grace deadline when the existing deadline has expired, even while the subscription remains unpaid. A later failure event restores paid-tier access for another seven days without payment.
> - **[P1] Accepted configuration can disable worker maintenance.** [schema.ts:614] accepts `overallDeadlineMs: 180000`, but the worker rejects values above `135000`. Saving this configuration makes retention/recovery ticks fail and prevents worker startup, including deletion processing.
> - **[P1] Backup expiry depends on successful backup creation.** [backup.sh:117] exits on dump/encryption failure before reaching expiry pruning at line 227. Repeated failures leave expired backups containing deleted customer data indefinitely, breaking REQ-A04's 30-day bound.
> - **[P1] Spin accepts an unchanged hook.** [similarity.ts:353] returns zero similarity when stopword filtering removes every source token. Identical hooks such as "If this is you" pass when subject and structure differ, breaking the documented requirement to change all three.
> - **[P1] Password-reset throttling targets the wrong endpoint.** [create-auth.ts:391] configures `/forget-password`, while the installed endpoint is `/request-password-reset`. Requests receive the library's three-per-minute limit instead of five per hour, allowing one IP to consume shared mail capacity much faster.
