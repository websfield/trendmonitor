## How each phase is run (keep this exact rhythm)

1. **Checkpoint without touching the worktree.** This is non-negotiable here: `sample-spin/run.ts` has a mixed-EOL index blob, so `git stash push` + `apply` aborts.
   ```bash
   SHA=$(git stash create "x") && git stash store -m "claude-jig checkpoint: respin-audit-remediation-2026-10-05 phase <N> (tracked; untracked in .git/claude-jig-checkpoints/P<N>-untracked.tar)" "$SHA"
   git ls-files --others --exclude-standard -z | tar --null -cf .git/claude-jig-checkpoints/P<N>-untracked.tar -T -
   ```
2. **Build.** Dispatch `respin-engineer` (run_in_background) with: the phase file, the master sections above, the register items, the skills to invoke, the disciplines, and the full validation set from `respin/`:
   - `pnpm typecheck && pnpm lint && pnpm test && pnpm build`
   - `pnpm preflight && pnpm worker:typecheck && pnpm db:check`
   - one live run with `TEST_DATABASE_URL=postgres://respin:respin_local_dev@localhost:5435/respin pnpm test`

   Tell it: no git, never kill a process by pattern, explicit timeouts on probes, LF line endings, and re-check every comment against the code after editing.
3. **Close the builder's own least-confident points** before the gate if they are cheap (a missing witness, a flaky test).
4. **Freeze.** Compute the file list against `stash@{0}` plus the tar, and the fingerprint. The working pattern is in this session's history: `git diff --name-only stash@{0}`, plus untracked files not in the tar, plus tar files whose content changed. Then `sha256sum` over `git hash-object` of each file.
5. **Gate** (`.claude/gate-rules.md`, `Gate intensity: lean`). Run billing and tenancy as **separate** runs when touched (`packages/credits` or `packages/config` always triggers billing). Compliance and learning run as **one merged** `general-purpose` run with `model: opus` and "think hard", with both checklists pinned. Add `security-reviewer` or `code-reviewer` where the surface warrants it (auth/OAuth, ops scripts, CI).
6. **Fix everything.** BLOCK/High → fix → one re-run of only those reviewers. Medium/Low → fix and note, no re-run. Same class on the re-run → stop and ask the owner (see the pattern above).
7. **Record.** Write `phase-<N>-card.md` (8 rows), append a `ledger.md` line, and update the master plan's progress row. Ready is only Ready if the findings say so.
