## What the review found, in plain words

**Round 1 (Not yet).** Every BLOCK was found by running code the passing suite covers, and none was visible to it:
1. **A near-copy in a field the gate did not read.** The similarity gate compared the reference hook only against hook-marked fields, while the spin screen renders the thesis, every beat and the caption. The reference hook verbatim in any of those three passed with similarity 0.00. Fixed at the class: the gate now compares every registered creator-facing text unit and names the one that carried the copy; a later field joins the gate by joining that population.
2. **A viewer who could write the feed.** The tracked-niche writers minted a profile scope carrying the role and never read it. Fixed with the repo's existing `ProfileRoleError` as the first act after the mint, witnessed with viewer, editor and owner seats.
3. **A worker that crash-looped from its second start.** `#ensureQueue` sent `policy` to `updateQueue`, which installed pg-boss 12.29.0 refuses unconditionally; the mocked runtime test accepted anything and the Docker proof never called it. The systemd unit would have restarted it every five seconds forever. Fixed by stripping the create-fixed keys by name, teaching the fake to refuse them like the installed one, and starting the real runtime twice on Docker Postgres. CLAUDE.md's 2026-08-18 lesson verbatim: a guard proved against a hand-picked option set, not the installed parser.

Plus the reachability finding all five reviewers made independently: outside tests nothing writes a trend item, so the slice is the master plan's own M2b-1 pattern (a package with no caller in its slice).

**Round 2 (Almost everywhere).** Zero BLOCKs. Every round-1 finding in the fix pass's scope was re-run green by the reviewer that raised it. The new CHANGEs were smaller and two were on the orchestrator's own seam wiring — the exact 2026-08-29 lesson (a guard call with no test that fails when it is deleted) caught by the billing reviewer within the hour.
