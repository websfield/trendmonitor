Creator-coaching evidence library — reviewed 7 September 2026

The intended product coaches TikTok and Instagram creators to make engaging content. This library supplies its evidence: durable techniques, reusable formats, sustained cultural themes and timely trends. Coaching should translate that evidence into an achievable concept, a hook, an execution plan and a lesson from the result.

This register contains 28 source entries and four restricted or outdated options. Separate entries from one provider represent distinct feeds or products. It is a curated foundation, not an exhaustive directory. The working scope remains global and English-first.

Pattern type, longevity, current momentum and effectiveness should be independent fields. A reusable mechanism can remain useful while a particular sound, wording or execution loses novelty. Evergreen is a candidate for continued reuse, not a performance guarantee.

| Knowledge layer | Examples | Coaching use |
| --- | --- | --- |
| Creative mechanisms | Curiosity, anticipation, surprise, tension and payoff | Explain the intended viewer response and how to create it |
| Reusable formats | Tutorials, demonstrations, before-and-after, stories with reveals | Give the creator a structure to follow |
| Sustained cultural themes | Aesthetic, lifestyle or topic communities | Find relevant angles for an audience over time |
| Specific executions | Particular sounds, catchphrases, challenges or editing templates | Add a timely option when it fits the creator |
| Creator-specific learning | Prior results, tested variations, feedback and constraints | Improve subsequent recommendations using authorized data or manual input |

Assign a separate longevity label: evergreen candidate, sustained, seasonal/recurring, short-lived or unknown. Lifespan is an assessment based on observations, not a fixed property of the category.

The proposed coaching flow is: understand the creator, recommend an achievable concept, coach execution, review results, then adjust the next recommendation. Capture platform, niche, audience, objective, experience, voice, time, equipment and on-camera comfort.

Each coaching card should include:

- A clear objective and content idea, with a short explanation of audience fit.
- A mechanism and reusable format, plus two or three hook variations.
- A practical script or shot sequence and the promised payoff.
- A current trend when relevant to the idea.
- One learning experiment and an outcome to review.
- Supporting examples and sources behind the recommendation.

Keep current momentum, repeatable effectiveness and creator fit distinct. A surge in adoption does not establish that a technique will achieve this creator's objective. Measure the intended outcome, such as retention, sharing, saving or conversion, against a suitable baseline. Retain counterexamples and distinguish observation from controlled testing.

The platform, vendor and publisher pages were reviewed. Vendor capabilities below are documented claims, not an independent accuracy audit. Paid products, authenticated APIs and native-app features were not tested. The JSON register includes evidence links, access notes and limitations for every entry. It contains source metadata, not harvested platform content.

For an initial coaching library, combine TikTok Creative Codes for reusable techniques with TikTok Creative Center, Creator Search Insights, Instagram native examples, Later, Buffer and Know Your Meme for discovery and context. TikTok's guidance explicitly includes hooks, suspense, surprise and emotion; its evidence concerns advertising and does not establish universal organic effectiveness. [Creative Codes](https://ads.tiktok.com/business/en-US/creative-codes?trk=article-ssr-frontend-pulse_little-text-block)

For automated data, evaluate TikTok Business Discovery and Modash first, then a music specialist if sounds are central. These are evaluation priorities based on functional fit; none is cleared here for customer-facing data reuse.

A few findings materially affect the app design:

- TikTok's July 2026 documentation describes Creative Center Trends through hashtags, related videos, audience insights and regional popularity. Do not build requirements from older four-tab screenshots without validating current availability. [Current TikTok help](https://ads.tiktok.com/resources/help/article/how-to-use-trends?redirected=2)
- TikTok's official SDK documents popular-hashtag discovery using an advertiser ID and access token. Treat access to your required endpoints as an implementation dependency; this review did not make authenticated calls. [Official SDK](https://github.com/tiktok/tiktok-business-api-sdk/blob/main/python_sdk/docs/CreativeManagementApi.md)
- Meta documents hashtagged-media discovery and other professional-account data through Instagram API with Facebook Login. I did not verify an official unrestricted global Reels/audio trend feed. [Meta API collection](https://www.postman.com/meta/instagram/folder/u4g5a2a/instagram-api-with-facebook-login)
- Tokchart's standard API terms allow internal analysis but require a separate written licence for redistribution and restrict competing products and persistent replicas. Its technical fit does not establish a usable default licence for this app. [Tokchart API terms](https://tokchart.com/api-terms)
- Talkwalker permits aggregate metrics while restricting automated export of Instagram content and raw TikTok data. It fits aggregate corroboration more readily than an exportable example-post library. [Talkwalker restrictions](https://developer.talkwalker.com/docs/getting-started/api-restrictions)

For source evaluation, ask each potential supplier for a sample from the same market, niche and date range. Compare timestamped records against original posts and audio pages, then measure observed refresh delay, missing examples, duplicate sounds and coverage of smaller creators. Confirm the exact fields, history, update commitments, allowed storage and customer-facing display in the proposed agreement. A dashboard subscription, downloadable file and OEM/data licence are separate questions.

For editorial sources, preserve the original post/audio link, author, entry date and the date you observed it. Store your own short trend explanation. Publishers can repeat one another, so count distinct underlying examples and creators rather than the number of articles naming a trend.

I recommend the following related record types:

| Record | Suggested fields |
| --- | --- |
| Source | source ID, owner, URL, evidence type, supported markets, documented access, rights status, last reviewed date |
| Pattern | stable ID, name, kind, explanation, mechanism/format relationships, longevity label, markets, languages, first observed date, lifecycle stage, confidence |
| Example | trend ID, platform, original post URL/ID, creator ID, publication time, sound ID, format notes, ad/organic/unknown |
| Observation | trend/source/entity IDs, observed time, provider update time if available, window, market, metric name/value/unit, reported/estimated/computed flag, sample definition |
| Coaching recommendation | creator context, objective, linked patterns, concept, hook variations, script/shot plan, payoff, experiment, supporting evidence |
| Creator learning | recommendation ID, published example, permitted performance observations, baseline, creator feedback, uncertainty and next adjustment |

Keep post counts, views, searches and proprietary scores as distinct metrics. A sound and a creative format can have a many-to-many relationship: one sound may support several trends, and one trend may use different sounds across platforms. Cross-platform matching should preserve each platform's IDs and evidence.

As an initial operating policy, review fast-moving candidate trends daily, seek adoption by several independent creators and compare at least two time points before marking growth as confirmed. Treat those as product-design starting rules to calibrate by niche, not as universal statistical thresholds. Record unknown values explicitly; missing data is not zero.
