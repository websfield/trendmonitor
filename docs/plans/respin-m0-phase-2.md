## Edge Cases & Failure Paths

- **Inverse events:** user/workspace deletion → FK `on delete cascade` on memberships (tested). Full REQ-A04 flow: deletion → build-plan **M6**, export → build-plan M2 (master-plan Deferral Ledger) — but the FKs must not block it structurally now.
- **Double failure:** migration applies but seed fails → seed is idempotent and rerunnable; test proves running it twice yields no duplicates (unique constraints).
- **Degraded mode:** `DATABASE_URL` absent → `createDb` throws a named, actionable error at call time (not import time); test proves it.

## Failure Modes & Degraded Behavior

| Boundary | Failure | Degraded behavior | Reconciliation | Proof |
|---|---|---|---|---|
| Neon (prod path) | unreachable / bad URL | named error at call time; no partial writes (single-statement bootstrap comes in Phase 3 as a transaction) | rerun after fixing env | test `createDb-missing-env` |
| drizzle-kit | schema drifts from committed migrations | `db:check` fails CI | regenerate migration in same commit | CI step + VS-4 |
| PGlite vs Neon | behavioral divergence | tests document PGlite as the harness (R-17); anything Neon-specific gets a `SHORTCUT:` marker naming the upgrade trigger | R-17 revisit trigger | R-17 entry |

## Handoff Contracts

- **To Phase 3:** `@respin/db` exports: `createDb`, `schema` (users, workspaces, memberships, role enum), types inferred from schema, and `migrate(db)` test helper applying committed migrations. Phase 3 builds `withWorkspace` and the bootstrap **on top of these exact exports** — changing them re-opens this phase.
- **Audience split (plan-review finding 5):** `createDb`, `schema`, and any raw-SQL entrypoint are for `packages/**` and tests **only**. `app/**` may import only the sanctioned surface Phase 3 defines (`withWorkspace`, `ensureUserWorkspace`, inferred types) — Phase 3's lint enforces this **default-deny** (`allowImportNames`, or a subpath split if that option is absent from the installed ESLint), because a route handler holding `createDb` + drizzle's `sql` tag could bypass `withWorkspace` with zero schema imports, and a denylist would silently admit exports added in M1.
