## Decisions baked in

- **Voice-build robustness without a second vendor call:** `AssemblyError` gains a closed `kind` (16 sites); the evidence-quote match tolerates typographic characters and whitespace runs but **stores the creator's original slice** as the quote, because the database's own provenance check refuses anything else (`with-workspace.ts:5737`); the refused state carries the kind and a static sentence per kind. Re-asking the model is parked with the money work because it is a second metered call.
- **Niche tier-block copy tracks the seed, pinned by test** (the `landing-pricing` precedent), rather than adding a facade read in `packages/credits`, which is parked.
- **The onboarding step "first ideas" means any generation for the profile** (any mode, including honest refusals), composed over the existing `generationsNewest` accessor — no new query text.
- **A decision entry amends R-68** (`/disclosure/` **traceability** findings stored at flag level, not listed in the draft's traceability list; claim findings — concealment, hard since R-69 — always listed); the owner approved its content and its traceability scoping on 2026-09-15.
- **Sign-up lands on `/onboarding`; sign-in keeps `/studio`.**
- **Step states are read, never inferred**; the one new read is a `withWorkspace`-scoped accessor modelled on `brainAssetSummary`.
- **Disclosure findings stay in the scan and leave the traceability list** (filter: disclosure prefix **and** flag enforcement); `claims` never filtered; the heading's "found" claims are scoped to "outside the disclosure guidance"; the provenance sentence says the guidance is product-written about the platform's policy and is checked against this product's list of concealment phrasings, a recall aid, not a complete check (R-69).
- **Honesty blocks are never folded**; native `<details>` only.
- **Journeys run nightly on the Free path.** Paid chapters are gated by `E2E_PAID_TIERS=1` and record a non-blocking "skipped: paid tiers not enabled" note when absent; CI hosts Postgres through `docker compose` (the journeys' DB shortcut shells into `respin-postgres`); the admin identity is minted per run by a bootstrap sign-up through the product's own UI so no persona can end in a skip that reads green.
- **Plan size:** Phase 1 is one phase of 42 file rows (about 48 distinct files; 41/~46 when accepted) because every task is a lake on the same first-session surface; the generalist could simulate it faithfully; the owner **accepted** the round-budget risk on 2026-09-15 (gate-rules §11; a warning disposition, not advance permission for any further retry).
