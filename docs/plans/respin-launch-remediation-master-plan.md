## Objective

Let a TikTok/Instagram creator with no starting concept find three worthwhile directions, develop one into a script and practical shooting plan, and reopen the chosen recording pack without paying again for retrieval.

## Non-goals

Full manual editing, silent/ASMR/multi-character formats, rendering, generated actors/voices, automatic publishing, agency approvals, analytics connectors, broad discovery, a memory framework, a pricing experiment, retroactive refunds and a Sample Spin rebuild. The [journey master](respin-creator-journey-master-plan.md) receives manual editing, series and richer feedback; connectors remain a conditional post-pilot package there. Existing hard integrity rules remain binding.

This plan authorizes no implementation on the parked money track, paid model run, new processor, live charge, customer admission, deployment or Claude-owned file. It makes the work reviewable; the named prerequisites below still apply when execution is requested.
