## Least confident

The echo bound of eight words. It is a chosen number in a phase whose other numbers are consolidations of numbers already chosen; the risk is false refusals on legitimate mechanism descriptions that borrow the transcript's phrasing. The card measures it over every autopsy fixture before the number is kept. **The fallback never narrows the field set:** P11-R3 and AC3 cover all four displayed fields because all four render (`trends-view.tsx:179-185` renders `hookMechanic`, every `beats[]` item, `ending` and `followTrigger`), and a check on `beats[]` alone would let a quoted `ending` reach the creator. So if the false-refusal count over the fixtures is not zero, the fallback is to raise the bound one word at a time to the smallest count at which it is zero, recording the count at each step in the card, up to a ceiling of **twelve**; above twelve the check would pass any quoted clause, so the phase stops there, keeps eight, records the finding, and lets the false refusals render "analysis unavailable" — the fail-closed direction for a pre-display gate — rather than ship a check that cannot fire. **A ceiling change is one edit to `AUTOPSY_MAX_ECHO_WORDS` (row 18) and re-derives everything downstream:** AC3 and row 19 assert against the imported constant (refuse at ≥ N, pass at N − 1), so they move with it and are never stale at "eight"; the fixture false-refusal count is re-measured at the new N and the card records the count at every N tried, so the number kept is the one the fixtures earned; and R-145 (row 20) records the value landed with its measured count beside it.
