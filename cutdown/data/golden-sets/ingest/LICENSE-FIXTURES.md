# Fixture licence — Cutdown ingest golden set

Every media file in this directory tree was **synthetically generated by ffmpeg** (v8.0.1,
gyan.dev full build) from its own built-in sources: `testsrc2`, `smptebars`, `color`, `sine`,
`anoisesrc`, the `flite` text-to-speech filter, and `drawtext` over locally installed system
fonts. The plain-text files (`.srt`, `.md`, `.rights.yaml`, `.xyz`) were hand-authored for this
corpus.

**Nothing here was downloaded. No real-world footage, photography, music, voice recording, logo,
or brand asset was used, adapted, or referenced.**

Consequently:

- No third-party copyright, performer, or trademark rights attach to any file.
- No person appears in or is audible in any file — the speech-like audio in `clean.mp4` and
  `mixed-job-valid/café shot.mp4` is machine-synthesised by `flite`, not a recorded human voice.
  No talent release is required or possible.
- No identifiable location appears in any file. No location release is required.
- These files are safe to commit to git, to redistribute with the repository, and to use in
  automated tests and CI without any rights review.

The `.rights.yaml` sidecars in `mixed-job-valid/` and `mixed-job-unsupported/` cite this file as
their `evidenceUri`. They describe *fixture* rights state, chosen to exercise the ingest rights
model — they are not, and must not be read as, a template for real client rights records.
